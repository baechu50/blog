# Blog publishing preferences

- Use `/og.png` as the default shared-link image.
- Do not assign individual representative images to existing posts unless the user explicitly requests it. Posts without `ogImage` use the site default.
- When registering a new post, ask the user which representative image to use if none has already been specified. Ask only for the new post; do not ask again for existing posts.
- Set a post-specific shared-link image through the optional `ogImage` frontmatter field. Do not insert it into the article body unless requested.
